# OIBSIP Task 3 - Temperature Converter Website

## Project Overview

The Temperature Converter Website is a responsive web application developed using HTML5, CSS3, and Vanilla JavaScript. It allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin with real-time validation and accurate conversion formulas.

## Objective

The objective of this project is to build an interactive temperature conversion tool that provides accurate results while handling invalid inputs and edge cases through proper input validation.

## Features

- Convert temperatures between Celsius, Fahrenheit, and Kelvin
- Displays all converted temperature values simultaneously
- Input validation for numeric values
- Absolute zero validation with user-friendly error messages
- Reset button to clear inputs and results
- Responsive user interface for desktop and mobile devices
- Modern and clean design using CSS

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any modern web browser.
4. Enter a temperature value.
5. Select the input unit.
6. Click the **Convert** button to view the converted values.
