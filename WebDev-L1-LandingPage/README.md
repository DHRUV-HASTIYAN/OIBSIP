# OIBSIP Task 1 - Landing Page

## Project Title
BuildSkill - Learning Platform Landing Page

## Objective
The objective of this project is to design and develop a responsive landing page using HTML5 and CSS3. The webpage showcases a fictional online learning platform, highlighting its services, features, and mission while following modern web design principles.

---

## Features

- Sticky Navigation Bar
- Responsive Hero Section
- Call-to-Action Button
- Feature Cards
- About Section
- Student Testimonial
- Footer with Contact Links
- Responsive Design using CSS Grid and Flexbox
- Smooth Hover Effects
- Mobile-Friendly Layout

---

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)
- CSS Grid
- Flexbox
