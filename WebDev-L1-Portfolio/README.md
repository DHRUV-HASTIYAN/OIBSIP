# OIBSIP Task 2 - Personal Portfolio

## Project Overview

This project is a responsive personal portfolio website developed using HTML5 and CSS3 as part of the Oasis Infobyte Web Development Internship.

The portfolio highlights my educational background, technical skills, projects, resume, and contact information through a clean and responsive user interface.

---

## Features

- Sticky Navigation Bar
- Hero Section
- About Me
- Education
- Technical Skills
- Project Showcase
- Resume Download
- Contact Information
- Responsive Design
- Smooth Scrolling
- Hover Effects

---

## Technologies Used

- HTML5
- CSS3
